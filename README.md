# FAMILY v0.1

空・雲・虹をテーマにした家族共有カレンダーの第1弾プロトタイプです。

## 今回入っているもの
- 月間カレンダー
- ちあき / そら / あお / とわ の初期メンバー
- 家族ごとの色分け
- 日付タップで予定追加
- 夕飯 / お弁当 の いる・いらない・未回答
- まとめ入力（同月の複数日を選択）
- 音楽予定
  - 学校の部活（とわ）
  - ジュニオケ（とわ）
  - ユースオケ（あお・とわ）
- 音楽予定に演奏曲 / 場所 / 時間を登録
- FAMILY画面で同居 / 別居 を表示
- メンバー追加
- localStorage保存
- PWA用 manifest / service worker

- 団体の追加・編集UI
- 帰省期間中だけそらの食事管理をONにする細かい期間処理
- 通知
