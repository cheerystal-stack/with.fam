# FAMILY v0.2

空・雲・虹をテーマにした家族共有カレンダーの第1弾プロトタイプです。

## 今回入っているもの
- 月間カレンダー
- ちあき / そら / あお / とわ の初期メンバー
- 家族ごとの色分け
- 日付タップで予定追加
- 夕飯 / お弁当 の いる・いらない・未回答
- まとめ入力（同月の複数日を選択）
- 音楽予定
  - 学校の部活（とわ）
  - ジュニオケ（とわ）
  - ユースオケ（あお・とわ）
- 音楽予定に演奏曲 / 場所 / 時間を登録
- FAMILY画面で同居 / 別居 を表示
- メンバー追加
- localStorage保存
- PWA用 manifest / service worker

## まだ未実装
- 家族間のリアルタイム共有DB
- ログイン / 各自の端末で自分を自動選択
- 団体の追加・編集UI
- 帰省期間中だけそらの食事管理をONにする細かい期間処理
- 通知
- アイコン


## v0.2 変更
- FAMILY画面から既存メンバーを編集可能
  - 名前
  - カラー
  - 同居 / 別居
  - 夕飯 / 弁当の対象
- 日付詳細に「編集」ボタンを追加し、既存予定を修正可能
- カレンダーの日付数字を固定配置
  - 予定が増えても日付の位置が動かない
- 日付詳細でメンバーを切り替えると、その人の夕飯 / 弁当状態を読み込み


## v0.3 experimental renovation
- 採用した空背景を実装
- カード/ボタンをアイシングクッキー寄りに調整
- 予定時間を6:00〜24:00・30分刻みの開始/終了選択へ
- 日勤/半日/遅番プリセット
- まとめ入力でも開始/終了時刻＋プリセット対応
- 6:00〜24:00の家族別デイリータイムライン
- メンバー削除（確認あり・過去予定は履歴として残す）
- 旧 `time: "09:00-17:00"` データを可能な範囲で startTime/endTime に移行
